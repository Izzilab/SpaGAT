# Original within-specimen sender analysis

This source is retained from WuBoFu/SpaGAT commit
38c27adc029715800e735999469cd6c15e98c076. It is the historical matched-count
sender implementation, with its corresponding model source. It is not the
independent-test brain benchmark. It requires the original compatible liver
checkpoint, model-ready inputs and receiver selection. The subsequent distance
and fixed-attention controls have separate source and notebooks in analysis/.
No historical random-split training or validation-only evaluation command is
provided as the root repository entry point.
